Songs

    Curator mode

    Paste a YouTube link or video ID to add a song. Titles can be typed in the list, or left empty to be filled in from YouTube when the song plays. Your draft lives in this browser only; export it to bake it into the file.

    Add several at once

    One song per line. A line can be just “Artist – Title”, a YouTube link, or a title and a link separated by “|”. With an API key (below) plain names are looked up on YouTube automatically; without one they are kept as “needs a link” with a “Search on YouTube” button in the row.

    The key is Google's official, free YouTube Data API key (roughly 100 look-ups a day). It is stored only in this browser and is never written into the exported file. How to get one is explained in the comment at the top of this file.

      Website settings (GitHub Pages)

      Lets “Save to website” write this file straight into your GitHub repository; GitHub Pages then updates within a minute or two. Create a fine-grained token at github.com/settings/personal-access-tokens with access to just this repository and “Contents: Read and write”. Everything here is stored only in this browser, never in the file.
